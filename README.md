# 🏥 EdgeHealth

Projeto de software obrigatório da escola **Cotemig**, desenvolvido em grupo, com foco em soluções voltadas para redes de empresas.

## 📋 Sobre o projeto

O **EdgeHealth** é um projeto acadêmico desenvolvido em equipe, com entrega prevista para o final do ano letivo. Atualmente, o projeto está na fase de **protótipo**, em desenvolvimento e sujeito a mudanças conforme avança.

## 👥 Equipe

Projeto colaborativo, desenvolvido por um grupo de alunos do Colégio Cotemig.

## 📌 Status do projeto

🚧 **Em desenvolvimento — Protótipo**

- [x] Definição do escopo e ideia inicial
- [ ] Desenvolvimento das funcionalidades principais
- [ ] Testes e ajustes
- [ ] Entrega final (até o fim do ano)

## 🎓 Contexto

Trabalho obrigatório da disciplina técnica do curso, com o objetivo de aplicar na prática conceitos de desenvolvimento de software em um projeto real.
